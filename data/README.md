## Section 2 - Billboard Dataset 

###  Ubaid Ullah - 9110715

### Dataset Name
Billboard Top 100 Song Rankings – Year 2000

### Description
This dataset contains Billboard Top 100 song rankings for the year 2000. Each row represents a song, while the weekly ranking columns (`wk1` through `wk76`) contain the song's chart position for each week after entering the chart.

### Primary Dataset Source
The dataset was obtained from the official `tidyverse/tidyr` GitHub repository.

Raw dataset:

https://raw.githubusercontent.com/tidyverse/tidyr/main/data-raw/billboard.csv

Official dataset documentation:

https://tidyr.tidyverse.org/reference/billboard.html

### Original Data Source
The official `tidyr` documentation identifies the original source as the **Whitburn Project**.

Whitburn Project reference:

https://waxy.org/2008/05/the_whitburn_project/

### Local File

The downloaded raw dataset is stored in this project as:

